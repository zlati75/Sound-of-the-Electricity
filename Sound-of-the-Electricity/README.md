# Sound of the Electricity

Уеб сайт на магазин за китари, ефект педали и усилватели. Страниците са обикновени HTML файлове със стил от `style.css`. Програмата на C е малък уеб сървър, който върши работата на JavaScript: попълва динамичните места в страниците, смята цените и държи кошницата. В сайта няма JavaScript.

## Стартиране

Програмата работи на Windows и на Linux (включително GitHub Codespaces). Стартирай я от главната папка на проекта, там, където е папката `site`.

**Windows (VS Code, MSYS2 UCRT64):**

```
cd Sound-of-the-Electricity
gcc -g -Wall -Wextra main.c -o shop.exe -pthread -lws2_32
.\shop.exe
```

**Linux / Codespaces:**

```
gcc -pthread main.c -o shop
./shop
```

Във VS Code компилирането е и на `Ctrl+Shift+B` (задачата `build` е в `.vscode/tasks.json`). При първото стартиране Windows може да поиска разрешение от защитната стена: разреши частните мрежи.

Сайтът работи на `http://localhost:8080`; друг порт се задава така: `shop.exe 9000`.

## Файлове

```
main.c              сървърът и логиката
data.h              цените и опциите за къстъм китарата
site/
  index.html        начало
  custom.html       къстъм поръчка
  cart.html         кошница
  info.html         информация
  style.css         целият стил
  img/              снимки на продуктите
  parts/            споделени части и продуктите
    head.html  header.html  footer.html  checkout.html
    guitars.html  pedals.html  amps.html
```

## Как се добавя продукт

1. Копирай един блок `<article>...</article>` във файла на категорията (`site/parts/guitars.html`, `pedals.html` или `amps.html`).
2. Смени на пет места: снимката, името в `alt`, името в `<h3>`, описанието, цената и `id` в `add?id=...`.
3. Сложи снимката в `site/img/` и я укажи в `src`.

Блокът трябва да запази този вид, защото C чете името, цената и `id` директно от него:

```
<article>
  <img src="img/g1.jpg" alt="Име">
  <h3>Име</h3>
  <p>Описание.</p>
  <span class="price">849 €</span>
  <a class="btn" href="add?id=g1">В кошницата</a>
</article>
```

`id` трябва да е различно за всеки продукт. Цената е число, последвано от интервал или `<`. Файловете от `parts/` се показват и на началната страница, и в категориите, затова един блок се копира само на едно място.

## Маркери в страниците

C заменя тези маркери, преди да изпрати страницата:

| Маркер | Какво се получава |
|---|---|
| `{{include:име}}` | съдържанието на `site/parts/име.html` |
| `{{active:страница}}` | `class="active"`, ако това е текущата страница |
| `{{cart_count}}` | броят продукти в кошницата |
| `{{cart}}` | таблицата на кошницата с общата сума |
| `{{summary}}` | изчислената цена на къстъм китарата |

Освен това C връща избраните отговори във формата (`checked` и `selected`), така че след изчисляване на цената те остават избрани.

## Цени на къстъм китарата

Цените са в таблицата `CHOICES` във файла `data.h`. Общата цена е сумата на избраните опции. Те са ориентировъчни и се променят там.

## Забележки

- Кошницата е една и се пази в паметта на сървъра, затова е обща за всички посетители и се губи при рестарт.
- Цените на продуктите са ориентировъчни; провери ги преди публикуване.
